## ✦ Listiq — my main project

A media tracker for movies, series, anime, manga, books and games. One library with ratings, reviews, lists, a social profile, swipe-style discovery and a Spotify Wrapped–style year in review.

**[Try the live demo — one click, no sign-up ↗](https://listiq-topaz.vercel.app/)**

<img src="https://raw.githubusercontent.com/cementix/listiq/master/docs/screenshots/landing-hero.jpeg" alt="Listiq landing page with a wall of real catalog posters" width="80%">

- **Product:** a private demo sandbox per visitor, a Pro plan on Stripe (test mode), CSV import from Letterboxd and Goodreads, insights with charts and an activity heatmap, public share pages
- **Engineering:** Next.js 16 (App Router, Server Actions), TypeScript, PostgreSQL + Prisma, 7 catalog providers synced by Vercel Workflow, rate limiting in Postgres, privacy enforced in database queries
- **Quality:** 74 unit, 29 integration and 5 Playwright end-to-end tests in CI on every push · Lighthouse 100 for accessibility · Docker setup

[Source code](https://github.com/cementix/listiq) · [Case study: how and why it's built this way](https://github.com/cementix/listiq/blob/master/docs/case-study.md)
